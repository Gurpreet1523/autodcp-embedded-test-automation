# Architecture Requirements\n\n1. Separate DCP service, ECU simulator, network client and test framework.\n2. Use a versioned, validated message schema.\n3. Make duplicate handling testable.\n4. Keep tests repeatable and isolated.\n5. Generate machine-readable CI results.\n6. Keep AI-generated tests separate from approved regression tests.\n7. Never commit secrets.\n8. Document limitations and avoid claims of real QNX or hardware testing.\n
